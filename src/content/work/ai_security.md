OutputFence is a lightweight validation layer that sits between a language model and the rest of your application. It enforces output schemas, runs content policy checks, strips rendering-unsafe content, and fingerprints outputs for anomaly detection.

Designed to be dropped into existing LLM integrations with minimal friction. Schema definitions are declarative; policy rules are composable. Works with any model provider.
