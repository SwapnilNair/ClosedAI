A data lineage and provenance system for ML training pipelines. Every document that enters the pipeline receives a cryptographic provenance record. Every transformation is logged. Every batch is sealed with a signed manifest.

Built on top of Apache Arrow and DuckDB for transformation logging, with a lightweight API for downstream consumers to verify provenance before using data.
